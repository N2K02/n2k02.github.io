One Android app for hosts and viewers
Watch together

Start with a movie.
Stay for the conversation.

MovieTogether is being built around shared playback without uploading a movie library to the cloud.

01 · Hosting

Bring your own movie

Select a supported local MP4 file. The host phone serves that selected movie from inside the app.

02 · Joining

Share a room invitation

Firebase-assisted room codes help other MovieTogether users discover a watch party.

03 · Together

Play in sync and chat

Follow the host's play, pause and seek controls, and send messages during the movie.

Current connection limits: Firebase finds rooms but does not carry the movie. Video still requires a direct connection to the host phone, such as on the same Wi-Fi or a properly routed private network. Different mobile networks may be blocked by carrier NAT. Direct streaming in the experimental app is not encrypted; use trusted networks.
Get together

Three steps to a shared screen.

1. Install the app

Both the host and guests install MovieTogether on Android.

2. Create a room

The host selects an offline MP4 and shares an invitation.

3. Join and watch

Guests join a reachable room and follow along, with chat alongside playback.
